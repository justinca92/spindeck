Your library, on a wheel you can feel.

Built for the Deck in your hands

Everything is reachable with the controller, follows Steam's look, and gets out of the way when you'd rather have Steam's own home.

🌀

Trackpad circle rotation

Rub the trackpad in a circle to spin the wheel, with Steam's radial-menu haptic on that pad at the strength you choose. On another controller the Deck stays quiet.

🎯

Game info at a glance

Rest on a game to see its playtime, when you last played, achievement progress and how many friends are in it right now.

🎲

Today's game

Can't decide? Press Ⓨ and a roulette spins the wheel and lands on a random game. Press Ⓨ again to stop it on the spot.

🔀

Main wheel + L1 / R1

Installed games, the whole library, ★ Favorites or any Steam collection, each with its own sort. Every view remembers where you were.

🖼️

Two layouts

A dial on the screen edge with the hero art beside it, or a wheel rising from a lower corner under full-width art.

✍️

Make it yours

Your own title in the corner (“j1's Steam Deck”), a subtitle and an accent colour. A dial odometer counts every turn you've ever spun.

Install in a minute

Spindeck installs from this project's GitHub releases through Decky Loader's developer mode.

  1. Install Decky Loader if you haven't.
  2. In Gaming Mode: Quick Access (…) → Decky → ⚙️ → General → turn on Developer mode.
  3. Open the Developer tab → Install Plugin from URL and paste the link to spindeck-x.y.z.zip from the latest release.
  4. Open Quick Access → Spindeck. The wheel replaces the home screen right away.

Later updates: press Check for updates at the bottom of the Spindeck panel. Decky asks once, and your settings are kept.

Speaks your language

Follows Steam's language automatically, or pick one in the panel. A built-in Hangul keypad covers Korean text, which Steam's keyboard can't type in Quick Access.

Leaves no trace

No telemetry and no background requests: GitHub is contacted only when you press Check for updates, and updates install only with GitHub's sha256 checksum. Turning the wheel off shows Steam's home, and uninstalling removes Spindeck's settings too. If a Steam update breaks something it relies on, you get Steam's original home instead of an error. Security policy

FAQ

Is it in the Decky store?

Not yet. It installs from GitHub releases with Decky's developer mode (see Install). It's also listed in DeckyHub.

Does it change my Steam settings or controller layout?

No. The trackpad input mode, the header styling and the hidden row are restored the moment you turn the wheel off or disable the plugin.

Which trackpad spins the wheel?

The left one by default, with the wheel on the left edge. Pick the right trackpad in the panel and the wheel moves to the right.

What if a Steam update breaks it?

Spindeck relies on Steam's internal UI, which can change. When something it needs is missing, it shows Steam's original home instead, until a new version is out.

Where do I report a bug or suggest an idea?

In the project's GitHub issues. For security problems, please use a private report.
